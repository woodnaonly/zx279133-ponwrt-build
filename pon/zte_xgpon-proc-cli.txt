# /proc/gpon_sdk/debug - the 44-command table read out of zte_xgpon.ko
# write syntax:  echo "<name> [args]" > /proc/gpon_sdk/debug
# the handler is called as fn(int, ...) after sscanf(rest, fmt, &a0..a6).
# The kernel answers in dmesg with "func <name> return success".
# An unknown token does not error - the write handler dumps this whole
# table into dmesg instead, so `echo nonsense > /proc/gpon_sdk/debug` is
# the read-only way to recover the vocabulary from a live unit.
#
# p* = print   (read only; output goes to the kernel log)
# s* = set     (writes real PON configuration)
# r* = remove, c* = clear   <-- destructive, they delete T-CONT/GEM entries
#
# one command is not in this table: `ssn <12 chars>` is matched before the
# loop and calls test_Configure_Ponmac_Set_Sn(), i.e. programs the SN.
