## 已覆盖的离线行为

- SHA256、标准 CRC32 及独立的真实 JFFS2 cleanmarker CRC 已知向量。
- 错板型、未知基底、元数据重复键、错误 target/兼容版本和固件长度。
- uImage 头/数据 CRC、声明长度、加载地址、类型和 gzip 头。
- 固定分区和 root 编号；拒绝布局不符、禁用祖先、重复关键节点、隐藏的第二分区表和 bootargs 分区覆盖。
- tar 截断、重复成员、错误哈希、链接/特殊文件、路径穿越、拼接归档及超长镜像。
- root → dtb → kernel 顺序；启动区只能写固定主程序窗口。
- 所有目标好块容量预检，不足时零擦除；坏块跳过不跨分区。
- 擦除/写页/ECC/读回失败不报告成功；失败后也核对受保护区域。
- 上传不完整不能确认；确认绑定任务和整包；缓冲区变更拒绝执行；重复确认不重刷。
- 同一份原生 C HTTP 服务：分段收发、Host/Origin/token、上传截断、写入锁定、确认响应断连后继续一次、写入期间拒绝重启和新任务、状态仍可查询。
- 同一份 lwIP + 桥接：内存 ARP/TCP 握手、错误校验和、重传不重复交付、接收环回绕及断连。没有向真实网卡发送数据包。
- 上电持续按住 3 秒的时间逻辑；未经实测标记的 GPIO 不被访问。
- 候选包生成的确定性、保护区修改拒绝、输出不覆盖；4 MiB 后备硬上限；ELF 结构与入口检查。

另外执行了固定种子的随机和突变输入检查。这些检查不是完整形式化证明，也不覆盖真实 NAND 控制器、DMA 一致性或掉电恢复。
